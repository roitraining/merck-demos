# Building Agents for Gemini Enterprise

## What students learn
Students learn how to design, build, and operationalize agents and skills in Gemini Enterprise. They start with simple prompt-based agents, configure knowledge-grounded agents in Agent Designer, create reusable Skills, and apply the workflow to a use case of their own.

## Case study
This course uses Cymbal Pharma, a fictional biopharmaceutical company. Learners build agent and skill workflows for clinical operations, medical affairs, and safety-style tasks. In the final lab, students step outside the scenario and define a use case of their own choosing.

## Labs

| # | Lab | Description |
|---|-----|-------------|
| 1 | [Creating Simple Agents](1-creating-simple-agents/creating-simple-agents.md) | Create two prompt-based agents: a Clinical Trial Briefing Assistant that structures trial updates, and a Trial Risk Desk that triages and escalates high-risk updates. |
| 2 | [Creating Agents with the Agent Designer](2-creating-agents-with-the-agent-designer/creating-agents-with-the-agent-designer.md) | Use the flow builder to configure knowledge-grounded agents: a Clinical Study Navigator (protocol synopsis) and a Safety Reporting Auditor. |
| 3 | [Creating Skills](3-creating-skills/creating-skills.md) | Create a reusable Trial Status Brief skill in Gemini Enterprise Skills and invoke it from chat with `/`. |
| 4 | [Bring Your Own Use Case](4-bring-your-own-agent-use-case/bring-your-own-agent-use-case.md) | Design and build your own agent or skill for a real workplace use case. |
